# 🛒 E-Commerce Mini

Aplikasi web full-stack sederhana yang menyediakan fitur daftar produk, keranjang belanja, dan simulasi checkout. Proyek ini dibangun menggunakan Node.js dan Vanilla JavaScript, serta dikonfigurasi untuk berjalan di dalam container Docker.

## 🚀 Fitur
- **RESTful API**: Endpoint untuk mengambil data produk dan memproses checkout.
- **Frontend Interaktif**: Katalog produk responsif dengan fitur keranjang belanja real-time.
- **Containerized**: Siap dijalankan menggunakan Docker dan Docker Compose.
- **Automated CI**: Dilengkapi dengan GitHub Actions untuk testing otomatis.

## 🛠️ Tech Stack
- **Backend**: Node.js, Express.js
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **DevOps**: Docker, GitHub Actions
